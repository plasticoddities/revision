HSC WRITING TOOLKIT

How to Answer

Use the question, command word, concepts and evidence to control your response.

Explain

Show how or why something occurs.

Analyse

Identify components and explain relationships.

Assess

Make a judgement using evidence.

Evaluate

Make a judgement about value, significance or effectiveness.

Discuss

Provide arguments and evidence from different perspectives.

PEEL

Point — make the argument.
Evidence — provide an example.
Explanation — explain how the evidence supports the argument.
Link — return to the question.

Building a 5-mark response

Define the key concept → provide an example → explain the example → link back to the question.

Building an extended response

Address the question directly, use key concepts, multiple relevant examples and a supported judgement.
